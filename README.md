# v.kochneva. Userinterface. Corporate Framework.

UI автотесты для сайта [https://userinyerface.com/](https://userinyerface.com/) на Python с использованием py-selenium-auto, PyTest, pydantic и паттерна Page Object Model.

---

## Как запустить проект
1. Клонировать репозиторий:

```bash
git clone https://github.com/vikochk/testing-userinyerface.git
cd <project_folder>
```

2. Установить Python 3.11+.

Если используется pyenv:

```bash
pyenv install
```

3. Создать виртуальное окружение:

```bash
python -m venv .venv
source .venv/bin/activate  # Linux/macOS
```

4. Установить зависимости:

```bash
pip install -r requirements.txt
```

5. Проверить конфигурацию в файле `tests/resources/settings.json`

Поддерживаемый браузер: Chrome. В конфиге можно изменить настройки: изменить ожидания или URL стартовой страницы.

6. Запустить тесты:
- Запуск всех тестов: `pytest`
- Запуск конкретного файла: `pytest tests/test_accept_cookies.py`

### Реализованные тесты
### Тест-кейс №1. Проверка сценария регистрации пользователя
Проверяет основной пользовательский сценарий прохождения первых этапов регистрации:

- переход со стартовой страницы на страницу регистрации;
- заполнение формы учетных данных (email, пароль, принятие условий использования);
- заполнение профиля пользователя;
- выбор интересов;
- загрузка фотографии профиля;
- переход к следующему этапу регистрации.

### Тест-кейс №2. Проверка сокрытия формы помощи
Проверяет работу виджета помощи на странице:

- отображение формы помощи после открытия интерфейса регистрации;
- корректную работу кнопки «Send to bottom»;
- скрытие формы помощи после взаимодействия пользователя.

### Тест-кейс №3. Проверка принятия cookies
Проверяет работу формы согласия на использование cookies:

- отображение формы cookies;
- обработку пользовательского согласия;
- закрытие формы после нажатия кнопки подтверждения.

### Тест-кейс №4. Проверка начального значения таймера
Проверяет корректность отображения таймера после открытия интерфейса регистрации:

- отображение таймера на странице;
- соответствие стартового значения ожидаемому значению из тестовых данных.
